注意が2つ

1. タイポ系はインラインで貼ること。文字が入ってるから <img> やと Anton が効かん。HTMLに直接書くか、ビルド時に埋め込む。

2. まっすぐな大判文字はCSSで書いたほうがええ。word-works みたいな水平の文字は、SVGにせんでもCSSの -webkit-text-stroke で同じ見た目が出せるし、そっちのほうが検索にも引っかかる。SVGが要るのはアーチ・円形・マスク抜きの3つだけや。

/* 水平の中抜き文字はCSSで足りる */
.giant { font-family: Anton; font-size: 12rem; color: transparent;
         -webkit-text-stroke: 2px var(--ink); opacity: .12; }

破れ系は画像素材とちごて 色がCSSで変わる・横幅を自由に伸ばせるのが利点。逆に紙の繊維感は出えへんから、リアルさが要る場所は画像素材のほうを使い分けて。

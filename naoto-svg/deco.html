使い方 
<svg class="deco"><use href="/sprite.svg#i-skyline-wide"></use></svg>

.deco { color: var(--ink); opacity: .12; }   /* 背景に薄く敷く */
.deco-accent { color: var(--vermil); }        /* 差し色として前に出す */

パターン系は <pattern> で組んであるから、要素のサイズを変えても模様の大きさは変わらん。背景に敷いても、マスクとして使ってもええ。

skyline と crosswalk と power-lines は preserveAspectRatio="none" 付きやから、横幅いっぱいに引き伸ばしても形が破綻せん。

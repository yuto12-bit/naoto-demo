ホームページ用画像

推奨ファイル：
street-pc-1400.webp : PC用 1400 × 1750 px
street-sp-700.webp : スマートフォン用 700 × 875 px

JPEGが必要な場合：
street-pc-1400.jpg
street-sp-700.jpg

調整内容：
元の写真・人物イラストを保ち、上下のグレーの余白を除去。
4:5の縦長画像としてサイズ調整し、ごく軽い輪郭調整と圧縮を実施。
AIで再生成したプレビュー画像は、このセットには含みません。
元の実画像は1179 × 1473 px。PC用は約1.19倍の拡大です。
元画像にない細かな情報を完全に復元する処理ではありません。

使い方：
WebPを優先し、JPEGは必要な環境用の予備として使えます。
picture-example.htmlに、768pxを境に切り替える実装例を収録。
画像の高さはautoにすると、人物を切らずに表示できます。
object-fit: coverを指定した固定高さの枠では人物が切れる場合があります。
スマートフォン用の700pxは、約350px幅の2倍密度表示に適したサイズです。
PC用1400pxは、1400px表示時には1倍密度です。
